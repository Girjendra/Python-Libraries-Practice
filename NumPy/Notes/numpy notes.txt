1 .Creating Arrays
1.1 From Python list
arr = np.array([1, 2, 3, 4])

1.2 2D Array
arr2 = np.array([[1, 2], [3, 4]])

1.3 Range of values
arr = np.arange(start, stop, step, dtype=None)
arr = np.reshape(a, newshape)
arr = arr.reshape(2, 10)
arr = np.linspace(start, stop, num=50)
arr = np.resize(a, new_shape) -> repeats or truncates elements if size is mismatched
1D arr = np.arange(1, 10, 2)
2D arr.reshape(2, 3)
2D np.reshape(arr, (10,2))


1.4 Zeros, Ones
arr = np.zeros(size, dtype=float) , size is (2,3) for 2D and (2) for 1D
arr = np.ones(size, dtype=float)

1.5 Identity Matrix
arr = np.eye(N, M=None, k=0, dtype=float)

1.6 Random Values 
arr = np.random.rand(d0, d1, ..., dn) , di is simension and range [0, 1)
arr = np.random.randint(low, high=None, size=None, dtype=int) , size is (2,3) for 2D and (2) for 1D

1.7 full()
arr = np.full(shape, fill_value, dtype=None)

1.8 Empty()
arr = np.empty(shape, dtype=float, order='C')


2. Array Attributes
arr.shape     # dimensions
arr.ndim      # number of dimensions
arr.size      # total elements
arr.dtype     # data type
arr.itemsize  # Size of each element (in bytes)
arr.nbytes    # Total bytes consumed by array
arr.T         # Transpose of array

3. Indexing
1D -> arr[i]
2D -> arr[i][j] or arr[i, j]

4. Slicing
1D -> arr[start : stop : step]
2D -> arr[row_start : row_end : row_step , col_start : col_end : col_step]

5. Vectorized Operations -> Every operation happens on entire array at once (NO LOOPS!)
arr = np.array([1, 2, 3, 4])
print(arr + 5)
print(arr * 2)
print(arr ** 2)
print(arr / 2)

6. Mathematical Functions
np.sum(arr)
np.mean(arr)
np.median(arr)
np.std(arr)
np.max(arr)
np.min(arr)
np.sqrt(arr)
np.sin(arr)

7. Reshaping Arrays
newarr = numpy.reshape(oldarr, newshape, order='C') or oldarr.reshape(newshape, order='C') , shape as (2,3) or (2) , Use -1 to auto-calculate
⚠ Rule : Total elements must remain same 

8. Flatten array
arr = arr.flatten() -> creates a copy
arr = arr.ravel() -> creates a view


9. Concatenation & Stacking
arr = np.concatenate((a, b), axis=0) , 0 means Row-wise and 1 means Column-wise
arr = np.vstack((a, b)) Same as axis=0
arr = np.hstack((a, b)) Same as axis=1
arr = np.column_stack((x, y)) Stacks 1D arrays as columns of a 2D array.

10. Broadcasting allows NumPy to perform operations on arrays of different shapes by expanding the smaller array automatically (without actually copying data).
Rule 1 : Compare shapes from right to left.
Rule 2 : Two dimensions are compatible if:
They are equal, OR
One of them is 1

11. Boolean indexing means selecting elements from a NumPy array using True/False conditions.
arr = np.array([10, 20, 30, 40])
print(arr[arr > 25])
mask -> A mask in NumPy is simply a Boolean array (True/False array) used to select elements from another array.
mask = arr > 20
print(mask) , mask → [False False True True]

12. Copying Arrays
b = a -> Shallow copy (linked)
b = a.copy() -> Deep copy (separate)
arr1 = arr.view()  Shallow copy (linked)


13. Loading & Saving Data
Save: np.save("data.npy", arr)	
Load: data = np.load("data.npy")

14. Matrix Operations
A = np.array([[1,2],[3,4]])
B = np.array([[5,6],[7,8]])

print(A + B)
print(A - B)
print(A @ B)     # Matrix multiplication
print(np.dot(A, B))
print(np.transpose(A))
np.add(x, y) → Adds two arrays element-wise. 
np.subtract(x, y) → Subtracts second array from first. 
np.multiply(x, y) → Multiplies arrays element-wise. 
np.divide(x, y) → Divides first array by second element-wise.

np.unique(arr)
